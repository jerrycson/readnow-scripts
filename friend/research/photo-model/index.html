한 문단 요약

Laurentini는 같은 시점에서 같은 윤곽을 만드는 물체들이 어떤 부분을 공유하는지 물었다. 외곽선으로 구한 입체 껍질과 실제 표면이 일치하는 부분을 식별할 수 있고, 보이는 윤곽에 영향을 주지 않는 오목한 곳은 구별할 수 없다고 설명했다. Matusik 등은 여러 영상의 윤곽에서 입체 껍질을 계산하고 그 표면을 입력 영상으로 표시했다. 이번 작업대는 브라우저가 저장한 외형을 정밀조형의 실제 얼굴 메시로 옮기고, 입력 전경은 촬영 방향이 맞을 때 별도의 겹침 층으로 보여 준다. 사진을 끄고 원형으로 돌아갈 수 있어 사진색이 주는 인상과 피부 좌표의 변화를 각각 시험할 수 있다.

A4 한 페이지용 상세 원고

상세 설명

정면에서는 윤곽이 같은 두 얼굴도 옆면에서 턱이 나오거나 들어가 보일 수 있다. 정면과 측면의 외곽이 모두 같아도 눈확이나 입술 사이 깊이가 다를 수 있다. Laurentini의 연구가 다루는 대상은 실루엣의 제약을 모두 만족하는 입체 껍질이다. Matusik 등은 색과 밝기를 가진 입력 영상에서 껍질을 그리는 방법을 제시했다. 여기서 얻을 수 있는 근거는 관측한 방향과 표면으로 확인 가능한 범위다. 사용자가 고른 임의 사진 다섯 장으로 동일 인물의 정밀 형상이나 촬영 렌즈를 알아냈다는 판정은 할 수 없다. 기존 작업대는 얼굴의 정면·앞 사선·측면·뒤 사선·뒷면을 받아 128×128 전경 마스크를 구한다. 사용자는 중심·축척·각도를 조절하고 붓으로 마스크를 정정한다. 같은 높이에서 각 마스크가 허용하는 폭을 교차해 외형을 만들고, 붓 편집과 OBJ 내보내기로 이어진다. 이번에는 사진 투영 농도를 0~100%로 바꿀 수 있게 기존 깊이 검사를 거치는 표면 투영기에 연결했다. 같은 방향에서 투영을 껐을 때도 입체 외형은 계속 보인다. 사진 판은 같은 브라우저의 보존함에 두고, 저장 시각과 판을 골라 적용한다. 정밀조형에서는 왼쪽의 기준 또는 후보 메시를 그대로 두고 오른쪽에서만 사진 외형을 적용한다. 머리 높이에 맞춰 각 띠의 둘레가 바뀌는 양을 옮긴 뒤, 원래 삼각면이 뒤집히지 않게 허용 변위 비율을 계산한다. 그 뒤에 기존 턱·볼 조형값과 목·턱 자세를 적용한다. 사용자가 사진 적용을 끄면 당시 선택한 기본형과 수동 조형값을 그대로 다시 렌더한다. 수동 편집을 공유하는 JSON에는 입력 사진과 기기 보존판을 넣지 않는다. 입력 사진의 전경을 겹칠 때는 저장된 촬영 방위와 중심·축척을 읽고, 모델의 턱·정수리 높이와 머리 중심에 맞춰 정사영 화면에 놓는다. 사진 한 장이 입체의 반대쪽이나 고개를 꺾은 자세에도 딱 맞는 듯 보이지 않도록, 좌우·상하 각도나 목·턱 자세가 다르면 겹침 층은 숨긴다. «사진 시점 맞추기»를 누르면 양쪽 모델이 같은 방향과 중립 자세로 돌아온다. 이 등록은 눈구석이나 콧방울의 다점 재보정과 렌즈 왜곡 보정까지 수행하지 않는다. 상체·하체·전신으로의 자동 복원과 다른 기기로의 사진 복원은 지원하지 않는다. 검증에는 사람이 찍힌 사진을 쓰지 않았다. 브라우저 안에서 방향마다 폭이 다른 타원과 색 표지를 그려 다섯 개의 합성 입력을 만들고, 실제 파일 입력·보존·형상 적용·끄기를 거쳤다. 오른쪽 메시가 달라지는 동안 왼쪽 캔버스의 화소가 동일한지, 적용을 끄면 두 캔버스가 다시 일치하는지, 카메라를 돌리면 사진만 숨는지 비교했다. 192×192 화면에서 같은 시점의 원형과 달라진 화소는 페른 3,835개, 힘멜 2,395개였다. 얇은 삼각면의 접힘을 제한한 뒤 허용된 사진 변위는 페른 19.4%, 힘멜 11.6%였다. 두 얼굴 모두 사진 외형을 끄면 원형 화소와 다시 일치했다. 합성 시험은 동작의 재현성을 확인한다. 실제 인물 다섯 촬영의 닮음이나 내부 구조 오차는 별도 실측이 필요하다. 원전의 도판이나 임의 사용자의 사진은 전재하지 않았다.

Laurentini, 1994 · Matusik 등, 2000
