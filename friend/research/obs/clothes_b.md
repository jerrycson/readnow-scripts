## 요약 규칙

1. **품(fit) 3단계는 한 숫자로 정한다 — 밀착 0~0.03H / 보통 0.05~0.1H / 헐렁 ≥0.15H(한쪽 기준).** 밀착 신축 옷(레깅스·스포츠브라·튜브)은 몸 윤곽 그대로, 주름 0~2(가로 당김선만). 보통 면 티는 0.05~0.08H, 헐렁 티·스웨터·후디·오버사이즈 블레이저는 0.15~0.2H. 소매 통은 팔 + 0.05H(보통)~0.15H(헐렁), 바지 통은 허벅지 +0.08H → 발목 +0.04H로 좁아진다. [근거: cf1a8722 품 0.05~0.08H·헐렁 ≥0.15H, 9770bd9f 밀착 0, af328fc4 블레이저 0.1~0.15H, 7b34aaf3 테이퍼, 2ee3783a, 360f728c, e891e20c]
2. **옷은 피부에 붙지 않는다(두께 규칙).** 목둘레·소매 끝·밑단 등 모든 옷 가장자리와 피부 윤곽 사이 틈 ≥0.02H(밀착 신축 옷만 예외), 가장자리에는 두께 선(이중선 또는 어깨선에서의 꺾임)이 있어야 한다. [근거: 9d86a2e3 ✓ 틈 0.03~0.05H, ✗ 틈 0]
3. **주름은 당김점에서만 난다 — 종류 6 + 옷감 2단계.** 늘어짐(수직, 중력) / 당김(한 점에서 방사, 각도 폭 ≤60°) / 압축(관절 안쪽, 짧고 촘촘 간격 0.03~0.05H) / 비틀림(나선, 몸 회전각 ≈ 주름 기울기 30~40°). 당김점 목록: 목둘레·어깨 솔기·겨드랑이·가슴 꼭대기(여성)·팔꿈치 안쪽·손(주머니/허리)·허리 밴드·가랑이·무릎·발목·단추·매듭. 평행 가로선 3개 이상 연속은 금지. [근거: a9495cea, 360f728c ✗/✓, 881b29bf, cf1a8722, f4ab0261, 4b389981]
4. **옷감별 주름 수(정면 상반신 기준).** 뻣뻣/두꺼움(가죽·코트·후디·데님·코르셋) = 0~5개, 굵고 둥근 윤곽, 관절에서만; 보통(면 티·셔츠) = 4~8개; 부드러움/얇음(실크·블라우스·긴 치마·스카프) = 10개 이상, 가늘고 끝이 사라짐; 신축 = 0~2. 바지: 가랑이 3~4 / 무릎 2~3 / 발목 2~3, 허벅지·정강이 0~1. [근거: a9495cea, 6373f09b, 7b36572c 가죽 팔꿈치 주름 상시, 7b34aaf3, 4b389981]
5. **여성 상의 당김점 = 가슴 꼭대기 2점.** 주름은 꼭대기에서 어깨 솔기(↗45°)와 겨드랑이(↘45°)로 각 1~2개(총 4~6), 가슴 사이 중앙과 가슴 아래 윤곽은 그리지 않는다(천이 꼭대기에서 수직 낙하 → 가슴 아래 몸판이 갈비에서 0.1H 떨어짐). 등 쪽은 가슴 당김이 없어 어깨→반대 골반 사선 1 + 허리 Z자 3단. 헐렁 상의는 꼭대기·중앙 3점에서 수직 낙하선 3개(길이 1.0~1.5H). [근거: cf1a8722, f4ab0261 玉 도식, 4b389981, 2ee3783a]
6. **밴드(커프·밑단·벨트·부츠 윗단)가 조이면 그 위에 블라우징이 생긴다.** 넘침 높이: 커프 0.05~0.1H, 니트 밑단 밴드 0.05~0.1H, 셔츠를 벨트에 넣으면 0.05~0.15H, 바지를 부츠에 넣으면 0.1~0.15H, 조거 발목 2~3단 쌓임. 밴드 폭: 골 커프 0.1~0.12H, 밑단 밴드 0.08~0.12H, 벨트 0.08H, 초커 0.04~0.06H. [근거: 360f728c, f4ab0261 たまる, 881b29bf, 4b389981, 2d9919d2 작업복, 2ee3783a ⑤, 103fe5be 머핀]
7. **밑단 위치 사전(턱 기준·7.3H 몸).** 크롭 = 가슴 아래 0.3~0.5H(배꼽 위) / 보통 티·셔츠 밖으로 = 가랑이 위 0.1H~가랑이 아래 0.15H(바지 밴드를 0.2~0.3H 덮음) / 라이더스·짧은 집업 = 허리뼈(골반 상단, 턱 아래 2.1~2.2H) / 교복 블레이저 = 엉덩이 중간(가랑이 위 0.3~0.5H) / 정장 재킷 = 가랑이 아래 0.1~0.2H / 후디 원피스·튜닉 = 가랑이 아래 0.5H. 치마·바지 밑단(가랑이 아래 기준): 데님 반바지 0.15~0.25H · 미니 0.3H · 무릎 위 0.7H · 무릎 1.1H · 미디 1.5~1.9H(종아리) · 맥시 2.6H(복사뼈) · 긴바지 = 신발 갑피 위 브레이크 1(0.03H 쌓임). [근거: 2d9919d2 9벌 %, 7b36572c, 9e4b3ae7, 62c19415[재측정], 40774901, 84afb3fa, b4ddaa01, af328fc4]
8. **바지 밑위(허리밴드 높이)는 배꼽 기준 3단계.** 보통 = 배꼽 ±0.05H(밑위 0.95H) / 높음 = 자연 허리선(배꼽 위 0.15H, 밑위 1.25H, 상의 넣음) / 낮음(허리뼈 라인) = 배꼽 아래 0.4~0.45H = 속옷 윗선(밑위 0.6H) / 힙행어 = 배꼽 아래 0.6H(지퍼 0.25H). 낮은 밴드는 골반 기울기를 따라 앞이 뒤보다 5~8° 낮다. 플라이 길이 = 밑위 × 0.6, 가랑이 수염 주름 좌우 각 2개. [근거: c8e18cb3[재측정], 103c8b6c, 4b5d3d65/b466e655, 6f587b09 속옷선, 6f532f0d]
9. **깃·단추·주머니 위치 표준.** 셔츠 단추 5개 간격 0.3~0.45H, 첫 단추 = 턱 아래 0.8H; 가슴 주머니 = 왼 가슴(보는 쪽 오른쪽), 윗변 = 젖꼭지 높이(턱 아래 0.95~1.0H), 폭 0.5~0.7 머리폭; 라이더스는 주머니 오른쪽만 + 비대칭 지퍼; 라펠 V 꼭짓점 = 첫 단추 = 정장 허리 위 0.3H(턱 아래 1.8H) / 교복 가슴 아래 1.1H; 세일러 V 꼭짓점 = 턱 아래 0.37H, 타이 길이 0.85H(허리까지); 넥타이 끝 = 벨트 상단, 느슨하면 매듭 0.1~0.2H 하강 + 첫 단추 풀림; 옆 플랩 주머니 = 밑단 위 0.3~0.35H; 카고 주머니 = 허벅지 바깥, 윗변 = 가랑이 높이; 벨트 버클 = 중앙선. [근거: b4ddaa01[재측정], 7b36572c, 40774901, 62c19415, bae3ea09[재측정], af3dcf33, 7d5cf224, 93529695, 2d9919d2]
10. **층 순서(안→밖)와 겹침 규칙.** 속옷/비키니 → 셔츠·티 → 타이/초커/목걸이 → 스웨터·조끼 → 블레이저/재킷/파레오 → 벨트는 바지 밴드 위·재킷 안. 안쪽 층의 밑단·소매는 바깥 층보다 짧거나(스웨터 밑단은 블레이저 밑단 위 0.3H) 바깥 소매 아래로 이어진다(레이어드: 긴팔 소매가 반팔 소매 아래로, 안쪽 통 < 바깥 통). 머리카락은 깃·목도리·모자 '위'에 얹히고 안으로 들어가지 않는다(짧은 보브는 깃 윗선과 턱 사이에서 끝남). [근거: ac9500a1, b52a5e37, 40774901, 7b36572c, bae3ea09, 1ee63e9d, 88b32c28]
11. **드리움(망토·긴 치마·늘어진 천)은 어깨/골반 곡면 위는 매끈, 그 바로 아래에서 가는 선으로 시작해 아래로 벌어지는 파이프 폴드.** 폴드 간격 위 0.05H → 밑단 0.2~0.3H, 정지 시 뒤 4~6·앞 3~5개, 긴 치마 정면 6~8개. 팔을 들면 손/팔꿈치가 제2 당김점이 되어 폴드가 그쪽으로 꺾이며, 천은 항상 팔의 바깥면에 얹힌다(뚫림 금지: 각 높이에서 천 단면 폭 ≥ 안의 몸 폭 + 0.05H, 바람 맞는 쪽 밀착만 예외). 밑단 물결은 진폭·주기 2종류 이상 섞고(균일 금지), 바닥에 닿으면 진폭 0.1~0.15H로 넓힌다. 바람: 바람 쪽 다리 윤곽 노출 + 반대쪽 부풀림(다리 폭의 2~3배). 앉으면 무릎이 주 당김점('쉼표' 주름). [근거: 843d324c, fd4e512b/37752ed2, a1763d7b, 79dc921e, fff3a69d]
12. **모자·머리띠·안경·귀걸이가 머리와 만나는 규칙.** 띠(모자 띠·화관·머리띠)는 두개골을 감싸는 '기울어진 띠' — 앞은 헤어라인 위 0.05~0.15H, 측면에서 20~30° 뒤로 기울고, 띠 폭 0.04~0.12H; 띠는 머리카락 위에 놓이되 0.02~0.03H 눌러 띠 위로 머리카락이 다시 부풀며, 앞머리는 띠 아래로 나온다. 챙 넓은 모자 챙 폭 = 머리폭 × 2.0~2.4, 베레는 15~20° 기울여 얹음, 캡을 뒤로 쓰면 챙이 뒤통수. 머리 뒤에 있는 장식은 머리에 가려 윗부분만 보인다. 깃털·리본은 귀 위에서 뒤로 뻗는다(얼굴 앞으로 나오지 않음). 귀걸이 = 귓불 아래 매달림(후프 지름 0.08H), 초커 = 목 중간, 팔찌 = 손목뼈 위 0.05H. [근거: 3fbced78, b148644d, 7f017a93, 2d9919d2 작업복, fff3a69d, b52a5e37, f9261e82]
13. **신발 = 발 두 도형(뒤 쐐기 + 앞 발가락 패드) + 굽 + 앞코 부풀림.** 신발 길이 = 발 길이 × 1.1~1.2(앞코 0.1~0.2는 빈 공간), 발 길이 ≈ 0.9~1.0H; 밑창 두께 0.06~0.1H(플랫폼 0.12H), 굽 스니커즈 0.05H / 펌프스 0.25H / 하이힐 0.3~0.35H(다리가 그만큼 길어지고 골반 앞으로 기움); 측면 높이 뒤 0.3~0.35·앞코 0.15 발 길이; 밑에서 보면 타원 + 뒤꿈치 선 끊김; 밑창 띠는 어느 각도든 끊기지 않는다. 부츠 통: 앵클 0.15H · 숏 0.3~0.4H · 종아리 0.5~0.6H(무릎 아래). 정면에서 발끝 10~20° 바깥. 양말 윗단: 발목 0.1~0.2H · 무릎 = 무릎 아래 0~0.1H · 무릎 위 = 무릎 위 0.1~0.15H. [근거: 5946f747, 295fe607, eb4ae405, b4ddaa01, 7b36572c, 9e4b3ae7, af328fc4, 2d9919d2, bae3ea09]
14. **소품 크기(머리 대비)와 쥐는 손.** 미니 백 폭 0.35~0.4 머리폭 · 트렁크/학생 가방 폭 0.9H×높이 0.5~0.6H · 펜 길이 0.3H(주머니 위 0.1H 돌출) · 손 길이 0.7~0.75H · 주먹 높이 0.35H·폭 0.3H(엄지가 검지 위를 가로지름). 늘어뜨린 손에 든 가방 상단 = 손 높이 = 가랑이 ±0.1H, 몸 옆 허벅지에 닿음; 어깨 가방 체인은 어깨에서 반대 골반으로 25~30° 사선, 가방 본체 골반 높이; 주머니에 넣은 손은 손목까지만 보이고 옷 밑단이 손 위로 걸쳐 가로 주름 3~4개; 치마 끝을 쥐면 밑단이 손 높이까지 올라가 안감 노출. 15. **팔 동작에 따른 옷 변화(정량).** 한 팔 올림 → 그쪽 밑단 0.1~0.15H 상승 + 겨드랑이 방사 3~4 + 소매가 어깨 쪽으로 밀림; 양팔 올림 → 밑단 0.2~0.3H 상승 + 양 손목 2점 당김; 팔짱 → 전완 교차 = 가슴 아래 0.2H, 소매 팔꿈치 안쪽 3~4 + 겨드랑이 사선 2; 손 허리 → 그쪽 옷 옆선이 손에 눌려 0.03H 들어가고 밑단 사선 0.1H; 팔꿈치 90° → 안쪽 방사 3~4, 바깥 0; 수평 팔 → 소매 윗선 직선 당김 2 + 아래 처짐 0.05H. - 층(안→밖): 속옷/비키니 → 셔츠·티 → 타이/초커/목걸이 → 스웨터·조끼 → 블레이저/재킷/파레오; 벨트 = 바지 밴드 위·재킷 안; 레이어드는 안쪽 소매가 바깥 소매 아래로 이어지고 안쪽 통 < 바깥 통; 스웨터 밑단은 블레이저 밑단 위 0.3H. [ac9500a1, b52a5e37, 40774901, 7b36572c]
- 깃: 셔츠 깃 끝 간격 0.4~0.5 머리폭, 캠프 칼라 폭 0.3 머리폭, 스탠드 칼라 0.2H, 하이칼라 0.35~0.5H 비대칭, 터틀넥 접힘 0.2H, 세일러 V 턱 아래 0.37H(등 플랩 = 어깨폭 0.6~0.65). [40774901, b4ddaa01, 9e4b3ae7, 6373f09b, 223b5006, bae3ea09, 9dd4f639]
- 단추: 셔츠 5개 간격 0.3~0.45H(첫 단추 턱 아래 0.8H), 블레이저 2개 간격 0.3H(첫 = 라펠 V 꼭짓점), 소매 단추 2~3, 라이더스 깃 스냅 2+2(지름 0.05H), 점퍼스커트 2열×3. [b4ddaa01, 40774901, 7d5cf224, 7b36572c, 7f017a93]
- 주머니: 가슴 = 왼쪽, 윗변 젖꼭지 높이, 폭 0.5~0.7 머리폭(라이더스는 오른쪽만); 옆 플랩 = 밑단 위 0.3~0.35H; 사선 입구 = 밑단 위 0.2H 폭 0.4 머리폭; 카고 = 허벅지 바깥, 윗변 가랑이 높이, 0.6 머리폭×0.5H; 캥거루 = 밑단 밴드 위, 폭 0.9~1.0 머리폭; 바지 앞 주머니 = 밴드 양끝에서 가랑이 쪽 호. [b4ddaa01, 7b36572c, 40774901, 9e4b3ae7, 93529695, 881b29bf, 84afb3fa, c8e18cb3]
- 벨트: 폭 0.08H, 버클 중앙(둥근/다이아몬드), 벨트 고리 좌우 1쌍 + 뒤; 리본 벨트는 자연 허리에 매듭(비대칭 가능, 중심에서 0.4 머리폭). [7b36572c, 40774901, b52a5e37, f9261e82, 04c74cc4]

**5. 모자·머리띠·안경·귀걸이가 머리·머리카락과 만나는 규칙**
- 띠 각도 20~30°(측면), 앞 = 헤어라인 위 0.05~0.15H, 띠 폭 0.04~0.12H, 머리카락 눌림 0.02~0.03H, 앞머리는 띠 아래로; 머리 뒤 장식은 가려짐; 큰 화관 윗선 = 두개골 윗선과 평행. [3fbced78]
- 챙 모자: 챙 폭 2.0~2.4×머리폭, 크라운이 머리 위에 얹혀 이마 노출, 양손으로 챙 끝을 잡으면 겨드랑이 90°. 베레: 15~20° 기울여 얹고 뒤가 뒤통수 덮음. 캡 뒤로: 챙이 뒤통수, 띠 = 헤어라인. [b148644d, 7f017a93, 2d9919d2]

- 귀걸이: 귓불 아래 매달림, 후프 지름 0.08H, 구슬형은 작게. 초커 = 목 중간 폭 0.04~0.06H. 목걸이 = 턱 아래 0.5H 펜던트. [b52a5e37, fff3a69d]

- 깃 ↔ 머리카락: 긴 머리는 깃 위에 얹히고 깃 안으로 들어가지 않음; 하이칼라와 턱선 간격 0~0.1H. [7b36572c, 6373f09b, 1ee63e9d, af3dcf33]

- 밑창 0.06~0.1H(플랫폼 0.12H), 굽 스니커즈 0.05H·로퍼 0.08H·앵클부츠 0.12H·펌프스 0.25H·하이힐 0.3~0.35H; 측면 높이 뒤 0.3~0.35·앞 0.15 발 길이; 밑에서 타원 + 뒤꿈치 선 끊김; 밑창 띠는 전 각도 연속. [eb4ae405, 7b36572c, f9261e82, af328fc4]

- 발끝 10~20° 바깥, 뒤꿈치 간격 0.8~1 머리폭. 샌들 스트랩 = 발등 가장 높은 곳(발 길이 0.4 지점), 발가락 끝 = 밑창 앞 0.02H 안. [b4ddaa01, 295fe607]

**7. 소품의 크기(머리 대비)·쥐는 손 모양·붙는 위치**
