단위: H = 머리 높이(턱~정수리) · HW = 머리 폭 · 각도는 ° · 실제 치수는 cm(한국 기준). "잰 값"은 원본 픽셀을 자로 잰 것, "약"·"보임"은 눈대중, "확인 안 됨"은 그림에 없음. 66장 전부를 원본 크기(작은 것은 3~4배 확대, 큰 것은 잘라서)로 열어 보았고, 그림 속 글은 전부 옮겼다(기존 노트 notes_00~09에 이미 전문이 있는 긴 글은 "기존 노트 전문 있음"이라 적고 수치·규칙 문장만 다시 옮김).

요약 규칙

  1. 옷은 몸 윤곽 바깥의 '두 번째 껍질'이다. 밀착(수영복·속옷·스타킹·스키니) = 몸 윤곽 그대로(여유 0 ~ 0.02H), 보통(티셔츠·셔츠·청바지) = 0.03~0.06H, 두꺼운 겉옷(후드·카디건·재킷·코트) = 0.08~0.15H, 헐렁(배기팬츠·망토·치마) = 0.3H 이상. 깃·소매 끝은 몸에서 떠서 '빈틈'이 보여야 한다(목 둘레 빈틈 0.03~0.05H, 반팔 소매 끝 빈틈 ≈ 0.1H). [근거: 395e2b32(붉은 옷 선이 검은 몸 선 밖 0.03~0.08H), cc3051f5(소매 끝 빈틈 ≈0.1H), 871d15f4(옷깃 띠 폭 0.06H), 9536a522·02c617da·2ee02fce(밀착 = 몸 윤곽), b94e51f9(스키니 밑단 빈틈 "気持ち" ≈0.02~0.03H), e771af54(후드 가장자리가 머리카락 바깥 0.10~0.16H)]
  2. 주름은 '당김점(tension point)'과 '쌓임점'에서만 생기고, 선은 쐐기(삼각형)로 당김점을 향한다. 당김점 = 어깨 끝·겨드랑이·팔꿈치 안쪽·허리(손을 주머니에 넣은 곳)·샅·무릎·가슴 꼭짓점(여성)·단추·매듭. 평행선 금지, 한 점에서 똑같은 길이의 방사선 4~5개 금지(1~2개, 길이·방향을 다르게). [근거: 750c011c "Triangles / avoid using parallel lines / Try to avoid repetition", ba8821cf "think of the lines are coming from one point", 699728d2 주름 자리 표, 29a6edf4(H·K·B·C·SS·Pull)]
  3. 주름 개수(그림이 보여 주는 수): 서 있을 때 티셔츠 3~6줄 전체, 반팔 겨드랑이 1~2줄, 팔꿈치 안쪽(구부림) 2~4줄, 무릎 뒤(구부림) 2~3줄, 바지 샅 좌우 각 1~2줄, 바지 밑단이 신발에 닿는 곳 2~3줄, 셔츠 소매 커프 위 3~4줄, 스키니 발목 쌓임 3~4줄, 단추 양옆 1줄씩(아주 옅게). 쉬고 있을 때는 더 적게("FEWER PANTS FOLDS WHEN RESTING"). 가슴 크기(여성)에 따라 티셔츠 주름 2~3줄(작음) → 4~6(보통) → 7~10+해칭(큼). [근거: dea2a02c, 699728d2, 871d15f4, 750c011c, 969fcb13(기존 노트) "左右3本ずつくらい"]
  4. 팔·다리를 굽히면 '안쪽 = 쌓임(복잡)·바깥쪽 = 당겨져 매끈한 한 줄(단순)'. 팔꿈치 바깥은 뼈가 천을 당겨 주름 0, 안쪽에 2~4줄(구부림이 90°에 가까울수록 많음, 마름모 '다이아몬드 접힘' 1개). 무릎도 같음(앞 매끈, 뒤 쌓임). [근거: 699728d2 "Elbows… outer side… no wrinkles… straight line", 0df866fc 재킷 소매, c81511bc "DIAMOND-SHAPED FOLDS", ba8821cf "simple side / complex side", 29a6edf4 SS(옆선=매끈)]
  5. 옷감 종류별: 뻣뻣(데님·코트) = 크고 불규칙한 주름 적게, 단단한 윤곽 · 보통(면 티) = 곡선 주름, 둥근 윤곽 · 부드러움(시폰·실크) = 가늘고 많은 세로 주름, Ω 모양 밑단 물결, 아래 층이 비쳐 보임 · 신축(니트·스타킹) = 몸을 따라감, 주름 거의 없고 골 무늬만. 두께는 밑단·소매끝의 '두 줄' 간격으로 보여 준다: 얇음 = 소매 폭의 1~2%, 두꺼움 = 10%. [근거: a08b0535 "Thin Fabric / Thick Fabric / Many Mangaka… 'thin' style", 699728d2 "thick denim creating large irregular creases", 16607bf8 시폰 설명, 53f4cc37 "skinny jeans / sweatpants … more flowy soft folds"]
  6. 드리움(긴 천): 천은 '가장 높은 접촉점'에 걸려 수직으로 떨어진다. 다리를 들면 들린 무릎이 새 접촉점이 되어 치마·통바지가 거기서 커튼처럼 떨어지고, 밑단은 든 쪽이 올라가며(무릎을 든 만큼) 든 다리의 정강이·발은 천 안쪽에 숨거나 밑단 아래로만 나온다. 밑단은 ㄱ자 상자가 아니라 처진 둥근 통("NOT ⌐ BUT 둥근 통"). 긴 치마 밑단은 선 다리 쪽은 바닥 근처, 든 쪽은 무릎에서 사선으로 내려온다(사선 = 중력선). [근거: dea2a02c "FOLDS POINT HERE / NOT / BUT", 0df866fc 같은 설명, 8138e49f 걷는 드레스(움직임 반대쪽으로 펼쳐짐)]
  7. 치마 구조: 허리띠(밴드)에서 시작해 엉덩이 가장 넓은 곳에서 퍼진다(가슴에서 퍼지지 않음). 교복 플리츠 = 허리 폭 0.9H → 밑단 폭 1.4H(1.5~1.6배), 길이 ≈ 1.1H(밑단 = 허벅지 중간, 크라운에서 3.5H), 앞면에 플리츠 8~10개, 밑단은 지그재그. 플레어·시폰 치마 = 밑단을 연속 물결(가운데 Ω, 양옆으로 갈수록 납작)로 먼저 그리고, 물결 꼭대기마다 허리로 올라가는 선 2줄(허리로 모임), 선 간격 균등; 겉 시폰 층은 밑 치마보다 조금 넓고 길이 3/4. [근거: e771af54(잰 값), 16607bf8 p.051 ①~⑥, 84e2fdfd(치마는 허리/엉덩이에서 퍼짐), c81511bc(바람에 들린 플리츠)]
  8. 층 순서(안→밖): 속옷·수영복 → 블라우스/셔츠/티 → 조끼·카디건·재킷·후드 → 벨트·가방끈·멜빵·넥타이·목걸이 → 모자·안경·귀걸이. 겹칠 때 보이는 것: 셔츠 깃·커프·밑단(밖옷의 V·소매끝·밑단 밖으로 0.05~0.15H), 넥타이는 조끼 아래로 들어가고 세일러 칼라·스카프는 조끼 위에 놓인다. 티셔츠·셔츠 밑단은 바지 허리띠를 덮거나(남 캐주얼) 안에 넣는다(교복·셔츠+데님). 배가 나오면 배가 허리띠 윗선을 덮는다. [근거: c81511bc(조끼 위에 세일러 칼라+스카프), 31e115b0·c81_R(카디건 V 안에 셔츠 깃·단추), cc3051f5·26e035a6(티 밑단이 청바지 허리띠 위), e771af54·b94e51f9(넣은 셔츠), 88bcd4a6·039bab95(배가 팬티·반바지 밴드를 덮음), 5c38b2f7·3fc95be8(멜빵이 맨가슴 위, 가방끈이 멜빵 위)]
  9. 깃·단추·주머니·벨트 위치: 깃은 목 둘레에서 0.03~0.05H 떠 있고 폭 0.06~0.08H; 셔츠 단추 간격 ≈ 0.3H(7개 = 목~허리), 폴로 2~3개, 열린 셔츠 4개(d622d9b5 노란 단추 간격 0.3H); 바지 주머니 입구는 허리띠 바로 아래 사선, 뒷주머니는 엉덩이 가장 넓은 곳; 벨트는 바지 허리띠 위 0.1~0.15H 폭, 버클 가운데; 허리띠·주머니·지퍼 선은 '두 줄'로 그려야 입체. [근거: 871d15f4, b94e51f9 p.065 ④ "各パーツの線は2重線にして", 26e035a6, 750c011c, dea2a02c]
  10. 모자: 모자 안쪽 테두리는 머리카락 껍질 안으로 0.02~0.05H 파고들어 앉고(머리카락이 눌림), 앞머리·옆머리는 테두리 밑으로 삐져나온다. 밀짚모자 챙 폭 ≈ 2.0×머리 폭(1.8H), 크라운 높이 챙 위 0.5H, 챙은 15~20° 아래로 처짐; 챙 그림자가 이마에 한 톤. 베레·작은 모자는 머리 옆에 비스듬히 얹히고 머리카락이 모자 둘레를 감싸 부푼다; 후드는 머리카락 바깥 0.10~0.16H에 테가 있고 앞머리는 안에 보이며 긴 머리는 후드 앞으로 흘러나온다; 귀덮개 모자는 귀 옆으로 덮개가 내려오고 곱슬 머리가 모자 뒤·아래로 나온다. [근거: d622d9b5(잰 값), 2c528dc8, 938665cc, e771af54 5번째, 16607bf8, 3fc95be8·18097887, 8138e49f 베레, 395e2b32 캡]
  11. 머리띠·안경·귀걸이: 머리띠는 머리카락 위를 가로질러 눌러 띠 앞뒤로 머리카락이 부푼다(c81511bc); 귀걸이는 귓불에서 아래로 0.1~0.2H 드롭, 머리카락 앞에 보임(b94e51f9, 84e2fdfd 브라이드·위치); 베일은 머리 꼭대기 장식에서 시작해 어깨 뒤로 몸통 중간까지(84e2fdfd). 안경은 이 묶음에 없음(확인 안 됨).
  12. 신발 = '둥근 돔(앞코) + 일정한 두께의 밑창 띠 + 발목 입구 타원'. 옆에서 길이 ≈ 1H, 높이(발꿈치 쪽 깃까지) 운동화 0.4~0.45×길이, 구두 0.33×길이; 밑창 두께 운동화 0.18~0.2×높이(≈0.08~0.1H), 구두 ½; 샌들 밑창 0.07H; 두꺼운 밑창(KAWAii) 0.2H; 펌프스 굽 0.25H; 앞코는 살짝 들림(toe spring). 정면 폭 = 발목 폭의 1.6~1.8배; 위에서 본 윤곽은 발꿈치→볼(길이의 65~70%)에서 가장 넓고 앞코로 좁아지며 안쪽(엄지) 쪽이 더 곧다; 다리 통은 신발 길이의 뒤 1/3 지점으로 들어가고 입구 타원은 카메라 높이에 따라 열리고 닫힌다. 부츠 통은 종아리보다 1.2배 넓고 발목에 가로 주름 2~3줄. [근거: a4c1685b, cbb14fdd, 93777084, c8cbaa9c, 56d9c395·52ba1cc4(맨발 구조), d622d9b5·938665cc(샌들), 16607bf8, b94e51f9, 220fec46]
  13. 양말·스타킹: 니삭스 윗선 = 무릎 아래 0.1~0.2H(잰 값 4.7H, 무릎 4.5H), 사이하이 = 무릎 위 0.4~0.6H, 윗선은 다리를 도는 타원이고 밴드 두께 0.03H; 사이하이 윗선에서 허벅지 살이 살짝 눌림(살 윤곽이 밴드 위에서 0.01H 부풀기). [근거: e771af54 잰 값, 16607bf8, c81511bc]
  14. 소품 크기·쥐는 법·몸 위치: 핸드백 높이 0.6H·폭 0.55H, 손잡이를 손가락이 감싸고(손에 가려지는 손잡이 부분도 그려 두기) 가방 윗선 = 손목 높이(4.0H), 가방 아래 = 허벅지 중간; 숄더백은 끈을 한쪽 어깨에 걸고 가방이 엉덩이 높이(3.6~4.0H), 끈은 몸을 따라 수직; 크로스백은 끈이 어깨→반대쪽 엉덩이로 사선(≈30~35°), 가방은 끈 반대쪽 엉덩이·허벅지 앞/뒤에 붙음; 끈 폭 0.05~0.12H; 포셰트(작은 가방) 0.5H. 긴 막대(지팡이·총)는 어깨 뒤 승모근 위에 걸치고 손은 어깨에서 0.8H 밖에서 손목을 꺾어 쥔다(4손가락 앞, 엄지 위). 책·휴대폰·컵은 이 묶음에 없음(확인 안 됨).   15. 판타지·해변·특수 복장 구조: 비키니 = 몸 윤곽 + 끈(0.03H)과 가장자리 선만, 매듭은 엉덩이 옆·목 뒤; 파레오(천 한 장) = 매듭이 주름의 원점(모든 선이 매듭으로 수렴); 망토(케이프) = 어깨 끝에서 걸려 팔을 감싸고 팔꿈치~팔뚝 중간까지, 몸 바깥 0.3H; 볼가운 = 밑단 폭 ≈ 3×어깨 폭, 바닥까지 내려와 발을 완전히 가림, 러플 3단; 기모노 소매 = 팔에서 무릎까지 늘어지고 오비 폭 0.5H; 마녀 벨소매 = 팔꿈치부터 입구 1H까지 벌어짐; 튜튜 = 가로로 1.3H 펼쳐짐; 메이드 = 퍼프 소매 + 앞치마가 치마 위 + 머리 프릴 띠; 배기(하렘)팬츠 = 허리·허벅지 앞·발목 커프 세 점만 닿고 폭은 다리의 1.3~2.5배, 커프 위 가로 쌓임 4~6줄.
