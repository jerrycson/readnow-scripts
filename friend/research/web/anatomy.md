# 사람 인체 — 한국인 실측 비율·관절 가동 범위·근육·손·발·보행·표정 (바이블 v2 조사 · 2026-10-29)

표기: **H = 머리 수직 길이(정수리~턱끝)**. 길이 단위 cm·mm(원자료 그대로), 각도 °, 24fps.
기준은 한국인. 성인 실측은 사이즈코리아 제8차(2020~2022 직접측정)를 1순위로, 없으면 7차·6차·5차 순. 어린이 키는 질병관리청 2017 성장도표와 교육부 2025 학생건강검사. 관절 가동 범위는 AAOS 기준표(Hendriks 2020 보충자료로 확인).
기존 조사(/home/claude/readnow-chats/mascot/research/anatomy/findings.md·sources.md·applied.md, notes_web.md §3·4·5, mascot_bible.md §1·2)와 겹치는 것은 "기존 조사 그대로"로 표시하고 넘어간다.
이번 세션 제약: 웹 검색 한도가 중간에 소진되어(에이전트 공용 한도) 보행·손가락 연동·표정 쪽 추가 출처를 더 찾지 못했다. 그 부분은 §6에 솔직히 적었다.

## 핵심 규칙

1. **1H(머리 수직 길이)의 실측값** — 한국 성인 남 23.5cm(6차 남 20~59세 평균 235.3mm [5]; 2004년 23.6cm [4]), 여 22.3cm(2004년 [4]), 남녀 혼합 15~69세 22.9±1.2cm(7·8차 합산 n=11,300, 턱끝~정수리 229.13mm [6]). **엔진 가정 1H = 22.5cm는 여성에게 맞고(−1%), 남성에겐 4% 작다 → 남성 객체는 1H = 23.5cm로 둔다.**
2. **두신지수(키/머리 수직 길이)는 1990년대 이후 7.2~7.3으로 고정** — 국가기술표준원 8차 발표 [1][2][3]. 8차 실측으로 다시 계산하면 20대 여 161.1cm ÷ 22.5 = **7.16H**, 20대 남 174.5cm ÷ 23.5 = **7.43H**, 6차 남 20~59세 171.4 ÷ 23.53 = **7.28H** [5]. 성인 객체의 "실측 등신"은 남 7.3~7.4, 여 7.1~7.2이다. 바이블의 여 7.0·남 7.5는 실측에서 ±0.2H 안쪽이므로 유지해도 된다(스타일 값으로 표기).
3. **다리길이비율(샅높이 ÷ 키)** — 8차 전체 남 45.3%·여 45.8% [1][2][3]; 20대 남 78.9/174.5 = 45.2%, 20대 여 73.1/161.1 = 45.4% [7][8]; 14~16세 여 46.0% [12]; 13~18세 남 46.0~46.1% [13]; 7~12세 여 45.9%, 13~18세 여 45.5% [14]; 60~85세 여 44.8% [11]. **결론: 7세부터 노년까지 샅높이는 키의 44~46%로 거의 일정하다.** 정수리→샅은 키의 54~56%, 즉 성인 남 4.07H·여 3.91H(머리 포함). 바이블의 "샅 = 50%"(3.75H/3.50H)는 다리를 약 0.2~0.3H 길게 그린 애니 스타일 값이다.
4. **무릎 높이(바닥→무릎점) ÷ 키 = 25.7~26.5%** — 20대 남 26.1% [7], 20대 여 25.7% [8], 14~16세 여 26.4% [12], 7~12세 여 26.5%·13~18세 여 26.1% [14]. 정수리→무릎 = 성인 남 5.49H·여 5.32H. 무릎 아래(정강이+발)가 샅→무릎(허벅지)보다 길다(남: 허벅지 1.42H vs 무릎 아래 1.94H) — 바이블 §2.2 결정 4 "정강이가 허벅지보다 길다"와 맞음.
5. **어깨점(견봉) 높이** — 정수리→어깨점 = 20대 여 30.7cm = **1.36H** [9], 20대 남 33.8cm = **1.44H** [7], 70대 여 29.1cm = 1.32H [11]. 바이블의 남 1.30H는 실측보다 0.14H 높다(남성 어깨를 더 내릴 것). 정수리→목뒤점(C7) = 여 24.9cm = 1.11H [8], 70대 여 23.2cm = 1.05H [11].
6. **팔 길이(어깨점→손목점)** — 20대 남 58.7cm = **2.50H**, 위팔 33.2cm = 1.41H, 아래팔(팔길이−위팔) 25.5cm = 1.09H [7]; 20대 여 53.7cm = **2.39H** [8]; 70대 여 52.0cm = 2.36H [11]; 13~18세 남 54.0~58.3cm, 여 52.5~54.6cm [13]. 어깨점에서 내려 계산하면 손목은 남 3.94H·여 3.75H, 즉 **샅보다 0.13~0.16H 위**(Loomis "손목 = 샅"보다 조금 높음). 팔꿈치는 남 1.44+1.41 = 2.85H.
7. **손 길이(손직선길이)** — 8차 남 20~69세 183.1mm = **0.78H**(23.5 기준) [15]; 여 성인 약 170mm = **0.76H**(2008 n=153, 유형별 168.6~172.4 [16]); 70~84세 여 169.6mm [17]. 손바닥/손 = 0.57, 손너비/손 길이 = 0.48 [15][17]. 바이블 여 0.68H는 실측(0.76H)보다 10% 작다.
8. **손가락 길이 비** — 8차 남: 검지 69.9 : 중지 78.0 : 약지 71.9 : 소지 55.2 : 엄지 50.7mm → **0.90 : 1 : 0.92 : 0.71 : 0.65** [15]. 노년 여: 0.91 : 1 : 0.96 : 0.76 : 0.68 [17]. 약지가 검지보다 길다(남 +2.0mm, 여 +3.4mm). 20대→60대 남성 손가락은 1.5~5mm 짧아지고 손바닥·손너비는 커진다(손직선길이는 183.0→181.6으로 거의 같음) [15].
9. **발 길이** — 8차 남 20~69세 발길이 256.4mm, 키 1736.5mm → **발/키 = 0.148**, 발/H = 1.09; 발너비/발길이 = 0.39; 뒤꿈치→새끼발가락 = 발길이의 0.825; 발목너비 72mm [18]. 5차 여 20~59세 발직선길이 232.3mm = **1.03H**, 발너비 91.8mm [19]. 바이블의 여 발 0.90H는 실측(1.03H)보다 13% 짧다(애니 축소 관행으로 표기).
10. **어깨·골반·가슴·허리 폭(실측 직선 너비)** — 20대 남 어깨가쪽사이길이 44.3cm = 1.89H, 어깨사이너비 40.1cm = 1.71H [7]; 20대 여 어깨너비(어깨사이너비) 35.2cm = 1.56H [8]; 50대 여 어깨너비 35.3·가슴너비 28.0·허리너비 27.4·엉덩이너비 33.1cm = 1.57·1.24·1.22·1.47H [10]; 50대 남 가슴너비 31.2·허리너비 30.1·어깨가쪽사이 42.0cm = 1.33·1.28·1.79H [20]; 14~16세 여 엉덩이너비 31.6cm = 1.44H [12]. 바이블 폭 값(여 어깨 1.48·골반 1.52, 남 어깨 1.85)은 실측 ±0.1H 안에 있다.
11. **목** — 목둘레 20대 여 31.7~32.0cm [8], 50~60대 남 38.5~38.8cm [20]; 둘레÷π로 환산한 목 폭 = 여 10.1cm = **0.45H**, 남 12.3cm = **0.52H**. 머리둘레 56.5cm(혼합 [6]), 남 57.2cm [5] → **목둘레/머리둘레 = 남 0.68, 여 0.57**. 바이블 여 목 폭 0.32H는 실측(0.45H)보다 30% 가늘다(애니 스타일 값으로 표기하고 '실사 모드'에서는 0.45H).
12. **머리 모양** — 머리너비 156.4mm, 머리길이(앞뒤) 181.2mm → 머리너비지수 0.86(국표원 발표 0.84~0.89, 단두형) [6][1]. 얼굴 길이(눈썹사이~턱) 남 118.6·여 111.9mm = 머리 수직 길이의 약 0.50~0.52 [6]. 아래턱사이너비 113.0mm = 머리너비의 0.72 [6].
13. **어린이 키(한국, 50백분위)** — 2017 성장도표 남: 6세 115.9 · 7세 122.1 · 8세 127.9 · 9세 133.4 · 10세 138.8 · 13세 158.6 · 14세 165.0 · 15세 169.2 · 16세 171.4 · 18세 173.6cm [21]; 여: 7세 120.8 · 10세 139.1cm [22][23]. 교육부 2025 학생건강검사: 초1 남 122.4·여 120.8, 초4 남 140.4·여 139.9, 중1 남 161.4·여 157.4, 고1 남 173.0·여 161.3cm [24]. 성장 고점은 남 14세·여 13세(8차 아동 조사, 1,118명) [25]. **12세까지 남녀 키 차이는 3cm 안쪽, 17세에 13.8cm.**
14. **어린이 비율(5차 여 7~12세, 키 대비)** — 목뒤높이 0.832 · 겨드랑 0.738 · 젖가슴 0.724 · 허리 0.623 · 배꼽 0.587 · 엉덩이 0.494 · 샅 0.459 · 무릎 0.265 · 장딴지 0.183 [14]. 13~18세는 목뒤 0.841·허리 0.628·샅 0.455·무릎 0.261로 거의 같다. **몸통 안의 비례는 7세부터 성인과 같고, 아이가 달라 보이는 것은 머리 수(두신지수)뿐이다.** 어린이 두신지수는 한국 실측이 없어 외국 실측(6세 6.36, 15세 7.5 [기존 S04])을 쓴다.
15. **나이 변화(실측)** — 여 키: 20대 161.1 → 60~85세 정상 153.7 → 70대 152.2 → 80대 149.6cm [8][11](코호트 차이 포함, 개인 노화만의 감소는 기존 조사 S14의 34년 −3.8cm). 70대 여 어깨점·C7 높이는 20대와 같은 비율(1.32H·1.05H)이므로 **노인 목·어깨 위치를 바꿀 근거는 없다**. 허리둘레/엉덩이둘레: 20대 여 0.77 → 50대 0.86 → 60대 0.90 [8][10]; 20대 남 0.85 → 50~60대(배꼽수준) 0.90~0.92 [7][20]. 중년·노인은 **허리 폭을 늘리고 엉덩이 폭은 거의 그대로**.
16. **관절 가동 범위(AAOS 기준, 정상 성인)** — 목 굽힘 45·젖힘 45·돌림 60·기울임 45 / 어깨 굽힘 180·젖힘 60·벌림 180·모음 40 / 팔꿈치 굽힘 150 / 손목 굽힘 80·젖힘 70 / 손가락 MCP 굽힘 80·PIP 90·DIP 65, 엄지 MCP 50·IP 80 / 엉덩이 굽힘 120·젖힘 20·벌림 40·모음 20 / 무릎 굽힘 135 / 발목 발등굽힘 20·발바닥굽힘 50 / 발가락 MTP 젖힘 70·굽힘 45 [26]. 손목 요측·척측, 전완 회내·회외, 어깨 회전, 엉덩이 회전, 흉요추는 Luttgens & Hamilton 표(요측 20·척측 30 / 회내 80·회외 80 / 내·외회전 90·90 / 엉덩이 내회전 40·외회전 50 / 흉요추 굽힘 45~50·젖힘 25·옆굽힘 25·돌림 30) [27]. **두 표가 다른 항목은 범위로 쓴다**: 목 굽힘 45~60·젖힘 45~75·돌림 60~80, 팔꿈치 140~150, 손목 굽힘 60~80·젖힘 60~70, 엉덩이 굽힘 100~120·젖힘 20~30, 무릎 135~150, 발목 발등굽힘 20~30·발바닥굽힘 40~50.
17. **일상 동작은 최대 가동의 약 70%** — 손목 기능 범위 굽힘 54·젖힘 60·척측 40·요측 17(기존 S09). 노인 손목 젖힘 −41%(기존 S10). **자세 풀이의 '편한 한계'는 규칙 16의 0.7배, '최대 한계'는 규칙 16 값.**
18. **승모근·흉쇄유돌근·실루엣 근육** — 기존 조사 그대로(바이블 §1.2·§1.3). 이번 조사에서 바꿀 근거를 찾지 못함.
19. **보행** — 기존 조사 그대로(입각 60%·유각 40%, 분당 80~110걸음, 유각 무릎 60~65°, 최소 발끝 간격 13~42mm). 한국 성인 분당 걸음 수·보폭/키·수직 진동·팔 흔들림 각은 이번 세션 근거 없음(§6).
20. **표정·주름** — 기존 조사 그대로(FACS AU 41개, 주름은 근육 방향에 수직). 나이별 주름 순서(눈가 → 40세 전후 이마·입가 → 60세 전후 뚜렷)는 notes_web §3-3의 Clip Studio 관행 값.

### 9. 피부·표정 근육

- 기존 조사 그대로(FACS AU 목록 S19, 주름 방향 S08).

## 우리 엔진에 적용하는 법

1. **설정 `anat.headCm`** — 객체별 1H 실측값(cm): F 22.5 · M 23.5 · 청소년 22.0/23.0 · 꼬마 19.0/19.3 · 노인 22.0/23.0. 발 들기(cm→H 환산)·접촉 높이 계산·'실사 모드' 환산에 쓴다. 범위 17~26.
2. **설정 `anat.realism`(0~1, 기본 0)** — 0 = 바이블 스타일 값(여 7.0H·샅 50%·목 폭 0.32H·발 0.90H), 1 = §2 실측표. 객체마다 두 표를 선형 보간한다. 보간 대상 키: `hc, crotchY, kneeY, shoulderY, c7Y, wristY, elbowY, shoulderW, hipW, neckW, handL, footL, armUpper, armLower`. 기본은 0이라 기존 그림이 바뀌지 않는다.
3. **남성 객체 어깨점** `shoulderY` 실측 1.44H(바이블 1.30H) — realism 0.5에서 1.37H. 어깨가 내려가면 목 노출이 0.29H로 늘어 남성 목이 보이게 된다.
4. **손목·팔꿈치 고정점**(바이블 법 3) — 실측 모드에서는 손목 = 샅 − 0.13H(남)·−0.16H(여), 팔꿈치 = 허리 − 0.15H(남)·−0.08H(여). 스타일 모드는 기존(손목 = 샅).
5. **ROM 클램프** — `rom.max`(§3 '최대' 열)과 `rom.easy`(×0.7)의 두 단계. 자세 풀이는 `easy` 안에서 먼저 풀고, 못 풀면 `max`까지 허용하고 '무리한 자세' 플래그를 켠다. 노인 객체는 `rom.max × 0.75`(손목 젖힘은 ×0.6, 기존 S10).
6. **나이·성별 폭 보정표** — 중년·노인: `waistW += 0.12H`(여)·`+0.10H`(남), `hipW += 0`, `bustY += 0.05H`(여, 처짐). 20대 WHR 여 0.77·남 0.85를 둘레 → 폭 환산 검증에 쓴다.
7. **손 부품** — 손가락 길이 비 0.90:1:0.92:0.71, 엄지 0.65(남)/0.68(여), 손바닥 0.57·손너비 0.48을 `hand.fingerRatio` 기본값으로. 노인은 손가락 −3%, 손바닥 폭 +4%.
8. **발 부품** — 발 길이 1.09H(남)·1.03H(여), 폭 0.39×길이, 발가락 사선 깊이 0.175×길이. 애니 축소는 `foot.styleScale`(기본 여 0.87·남 0.96)로 따로 둔다.
9. **머리 타원** — 정면 폭 0.66H(156/235)·측면 앞뒤 0.77H(181/235), 얼굴(눈썹사이~턱) 0.51H.
10. 바이블 §2.2 표 각주에 "실측 대비: 샅 −0.3H, 남 어깨 +0.14H, 여 목 폭 −0.13H, 여 발 −0.13H는 스타일 선택"을 적어, 다른 AI가 실측으로 오해하지 않게 한다.
