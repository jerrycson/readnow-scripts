사람 움직임 — 실제 · 풀 애니메이션 · 아니메 세 양식 비교와 엔진 적용 (웹 심화 조사 · 2026-10-29)

기준: 24fps(1f = 41.7ms) · 단위 cm·kg·°·초·프레임(f) · H = 전신 높이, 머리 = 정수리~턱. 표기: [출처 n] = 아래 '출처' 목록 번호에서 수치를 직접 확인 · [기존] = 기존 조사(research/motion/findings.md, notes_web.md, mascot_bible.md §11)에 이미 있는 값 · [관행] = 출처에 수치가 없어 업계 관행으로 잡은 시작값 · [유도] = 출처 수치로 내가 계산한 값(계산식 병기). 기존 조사와 겹치는 것은 '기존 조사 그대로'라고만 적고, 이번 조사는 빠진 것·출처 없던 것·세 양식 구분을 채우는 데 집중했다.

핵심 규칙 (바이블에 그대로 넣을 것)

  1. 양식은 설정 하나로 고른다 — motion.style = real / full / anime. 세 양식의 차이는 "그림 장수(코마)·정지 길이·간격 곡선·과장량·2차 운동·잔상" 7가지 매개변수 묶음이고, 그 밖의 뼈대·리그는 공통이다. 세 양식 모두 재생은 24fps 고정이며 바뀌는 것은 값이 갱신되는 프레임 간격뿐이다(1코마 24장/초 · 2코마 12장/초 · 3코마 8장/초). [출처 1][출처 2][출처 3][기존]
  2. 아니메(3코마)는 평균값이지 고정 규칙이 아니다. 한 컷 안에서 큰 동작은 2코마·1코마, 정지 대사는 4코마 이상으로 섞어 쓴다. 엔진은 '트랙별 코마'를 둔다: 몸 동작 2~3코마, 얼굴(눈·입) 2~3코마, 호흡·시선·물리(머리카락·옷)는 항상 1코마(계단화 금지). [출처 2][출처 3][기존 notes_web §1-1]
  3. 실제 걷기 기준값(생체역학): 케이던스 100~115걸음/분(≈1.67~1.92걸음/초 → 한 걸음 12.5~14.4f), 편한 속도 약 80m/분(1.33m/s), 입각 60% : 유각 40%, 이중 지지 걸음당 10%+10%. [출처 4][출처 5][기존 S13 1.83걸음/초]
  4. 실제 걷기 몸통 수치: 무게중심 상하 진폭 = 신장의 2.16%(170cm면 약 3.7cm · 걸음마다 1회 오르내림, 양발 지지(접지) 때 최저 · 한발 중간 입각 때 최고), 좌우 진폭 = 신장의 1.34%(약 2.3cm, 빠른 걸음에서 0.25%로 급감). 골반 회전 ±5°, 골반 좌우 기울기(obliquity) ±5°, 골반 앞뒤 기울기 변동 5°(평균 전방 10°). 무릎: 접지 10° → 하중 20° → 중간 입각 5° → 발 떼기 40~50° → 유각 초 60° → 유각 말 5°. 엉덩관절: 접지 굽힘 35° → 입각 말 폄 −10°. 발목: 접지 −5° → 중간 입각 +10~15° → 발 떼기 −25°. [출처 6][출처 7]
  5. 풀 애니 걷기(Williams 공식): 한 걸음 12f가 '보통·활기찬 걸음'(2걸음/초). 4f 매우 빠른 달리기 · 6f 달리기/매우 빠른 걷기 · 8f 느린 달리기/만화 걸음 · 12f 보통 · 16f 산책 · 20f 노인·지친 걸음 · 24f 느린 걸음 · 32f 매우 느림. 키 순서는 접촉(contact) → 내림(down) → 통과(passing) → 올림(up) → 접촉이고, 12f 걸음의 키 위치는 접촉 1 · 내림 3~4 · 통과 7 · 올림 9~10 · 접촉 13(자료마다 3/4·9/10 차이). 높이 순서: 올림 > 통과 > 접촉 > 내림. [출처 8][출처 9][출처 10][출처 11]
  6. 아니메 걷기(作画 관행): 전문학교 정규 과정의 기본 과제는 "횡걸음 3코마 중(中) 4장"이다 — 접촉 원화 둘 사이에 동화 4장, 즉 한 걸음 5장 × 3코마 = 15f/걸음(0.625초, 96걸음/분). 실제 사람 케이던스(100~115/분)와 거의 같아, 아니메 걷기는 "장수를 줄이되 시간은 실제와 같게"가 원칙이다. 달리기는 한 걸음 4~5장 2코마(8~10f), '아니메식 대시'는 공중 그림을 빼고 4장을 2~3코마. [출처 12][출처 13][출처 14]
  7. 실제 서 있을 때 흔들림(자세 동요): 압력중심(COP) RMS 앞뒤 0.6~0.7cm · 좌우 0.4cm, 평균 속도 앞뒤 0.5~0.65cm/s · 좌우 0.3~0.5cm/s, 주 주파수 앞뒤 0.11Hz(눈 뜸, 주기 약 9초) · 0.20Hz(눈 감음). 몸 각도로 환산하면 발목 기준 ±0.3~0.5°(복사뼈~무게중심 100cm 가정: atan(0.6/100)≈0.34°). 즉 '실제' 양식의 몸 흔들림은 Live2D 예시(BodyAngleX ±2°/15.5s)의 약 1/5이다. [출처 15][출처 16][출처 17][유도]
  8. 풀 애니 대기 = 무빙 홀드: 같은 그림을 8~12f 넘게 두지 않는다. 키 포즈 대비 1~3% 드리프트(ease-out) + 부위별 도착 프레임 엇갈림 + 깜박임·호흡. 아니메 대기 = 정지 그림 + 깜박임 + 머리카락 물리만(몸은 계단화 정지). 아니메 연구(쓰쿠바대 2013)는 이것을 '코마도리(コマ撮り)=거의 정지인 프레임은 갱신하지 않음'과 '나카나시(中無し)=중간 그림을 빼서 속도를 과장'으로 정의한다. [출처 18][출처 19][기존 notes_web §1-6]
  9. 깜박임 세 양식: 실제 — 평균 간격 4.3초(2~6초 무작위), 닫힘 2f·감음 1f·열림 3f(총 6f). 풀 애니 — 같은 모양에 눈썹 2~5% 동반 하강, 머리 15° 이상 돌림 시작 0~2f에 강제 깜박임. 아니메 — 그림 3장(뜸·반·감음), 기본 순서 뜸→감음→반→뜸(닫을 때는 중간 그림 없이 '탁' 감고 열 때만 반 그림), 8fps 타임라인 기준 4프레임 = 24fps에서 3코마 × 4 = 12f(0.5초). 느리게 보이려면 닫을 때도 반 그림을 넣는다(5장). [출처 20][기존 §3.11]
  10. 입 움직임(아니메 口パク): 입 그림 3장(닫힘·반·열림). 무작위 교체는 떨려 보이므로 고정 루프를 쓴다 — 원 자료(15fps) '열림 3 + 반 3 + 열림 2 + 닫힘 2' = 24fps 환산 열림 5f → 반 5f → 열림 3f → 닫힘 3f(16f ≈ 0.67초), 말할 때만 돌리고 침묵이면 멈춤. 긴 '아·오'는 열림 유지, '이·우·에'는 반 유지, '응'은 닫힘 유지. [출처 21][유도]
  11. 표정 전환 순서(세 양식 공통): 시선 0f → 눈썹(바깥 먼저) +0~2f → 눈꺼풀 +2~4f → 입(모양→열림) +3~6f → 머리·몸 +4~8f → 홍조·땀 +6~12f. 전환 길이: 보통 6~10f · 미묘 12~20f · 충격 2~4f. 아니메는 중간 그림 0~1장(中無し 또는 中1枚)으로 '탁' 바뀌고, 풀 애니는 중간 2~4장, 실제는 연속. [기존 §3.10][출처 19]
  12. 잔상(스미어)·오바케: 스미어는 "가능한 한 적은 프레임, 대개 1프레임"이며 2·3프레임 유지하면 틀리게 보인다. 풀 애니에서만 쓰고(빠른 턴·펀치·손 흔들기 시작), 아니메는 같은 자리에 오바케(ブレ) 그림을 1~2코마 넣는다. 실제 양식에서는 쓰지 않는다. prefers-reduced-motion이면 스미어·잔상만 끄고 몸짓은 유지(엔진 기존 msc2RMfx 규칙). [출처 22][출처 23][출처 14]
  13. 이펙트(SF·판타지) 작화 수치: 불꽃 한 사이클 6~8장(반복 루프면 약 16장), 반짝임 효과는 2코마 노출(사이에 색 셀 삽입 가능), 빔은 한 그림 1~2f + 다른 그림 2~3f를 10f 안에 채움, 충격은 충격 프레임을 빼면 속도감, 충격 뒤 블러 그림 1장을 넣으면 힘. 반짝이(キラキラ)는 4장 × 2f = 8f(1f/장은 너무 빠름), 놀람 기호는 2장 교대 4f. 폭발은 지브리 기준 표준보다 1.3배 느리게. [출처 24][출처 20]
  14. 끊고 들어오기(블렌딩) 업계값: 게임 엔진의 전환(크로스페이드)은 초 단위 고정 길이로 두며 예시값 0.1~0.4초(Spine 기본 0.1s 예시, 쌍별 0.2·0.25·0.4s, 걷기→사격처럼 즉시 바꿀 때 0s, 셋업 포즈로 돌아갈 때 1.5s). Unity는 Exit Time(정규화, 예 0.75) + Transition Duration(초 또는 정규화) + Interruption Source(None/Current/Next/둘 다)로 끊기 규칙을 두고, Unreal은 Blend In/Out(사용자 예시 0.25s)과 Sync Group(리더·팔로워, 발 접지 마커로 시간 맞춤)을 쓴다. 우리 엔진 MSC_XFADE 200ms(≈5f)는 이 범위 안이다. [출처 25][출처 26][출처 27][출처 28]
  15. 두 캐릭터 동기화 관행(게임식): 접촉이 있는 짝 동작은 두 리그의 '접촉 마커' 프레임을 같은 시각에 놓고, 나머지 구간을 리더(먼저 시작한 쪽) 길이에 맞춰 팔로워의 재생 속도를 비례 조정한다(Unreal Sync Marker 방식). 길이 차가 크면 속도 튐이 생기므로 짝 동작의 길이 차는 ±25% 안으로 설계한다(±25%는 [관행]). 아니메·풀 애니 교재에는 이에 대한 수치 규정이 없다(근거 없음). [출처 28][관행]
  16. 찌그러짐·늘임(스쿼시·스트레치) 허용량: 실제 0%(뼈대는 변형되지 않음) · 풀 애니 몸통 ±5~10%, SD·착지 ±15~25%, 부피 보존 scaleX×scaleY≈1 · 아니메 몸은 0~3%(거의 쓰지 않고, 개그·SD 컷에서만 풀 애니 값). 출처에 정량 규정은 없고 부피 보존 원칙만 있다 — 숫자는 [관행]. [출처 1][기존 notes_web §1-10]
  17. 2차 운동(머리카락·옷) 늦음: 실제 = 물리(진자·감쇠, Live2D 값 그대로) · 풀 애니 = 부위별 지연 앞머리 1~2f · 옆머리 2~3f · 뒷머리 3~5f · 치마 3~6f · 리본 4~8f, 오버슛 10~50% · 아니메 = 같은 지연이지만 2~3코마로 계단화하고 몸이 멈춘 뒤 1~2회만 흔들고 정지. [기존 notes_web §1-5][관행]
  18. 호흡·체중 이동은 양식과 무관하게 '실제' 값을 쓴다(성인 3.2~3.6초, 들숨 40%:날숨 60%, 체중 옮김 6~15초마다 24~36f). 단 아니메 양식에서는 체중 옮김만 2코마 계단화. [기존 §11.1]
  19. 양식 전환 시 바뀌지 않는 것: 뼈대·가동 범위(§1.4)·표정 순서(규칙 11)·호흡·깜박임 간격·물리 60fps 고정 스텝. 바뀌는 것은 '우리 엔진에 적용하는 법' 표의 매개변수뿐이다.

구현 메모 - 계단화는 값 갱신 시각만 floor(t/koma)*koma로 묶고, 이징 계산 자체는 연속으로 해 둔다(코마를 바꿔도 동작 길이가 변하지 않음 — [출처 32] "12프레임 이동은 코마 수와 무관하게 같은 시간"). 기존 msc2Io(sine io)와 MSC_EASE.io 중복은 하나로 합친다(기존 applied.md). - stepF는 MSC2K.stepMs(460ms·짝 접근용)와 분리해 걷기 모드 전용으로 둔다(기존 applied.md 지적 유지). 95걸음/분(632ms=15.2f)은 아니메 양식 15f와 거의 같으니 anime 기본값으로 그대로 두고, real 13f·full 12f를 추가. - 아니메 걷기의 그림 5장은 '키 포즈 5개를 계단 재생'으로 구현(중간 보간은 코마 사이에서만). 몸 트랙 계단화 중에도 물리·호흡은 1코마. - 표정 트랙은 얼굴 코마를 따르되, 규칙 11의 부위 순서(눈썹→눈꺼풀→입)는 코마 경계에 정렬한다(아니메 3코마면 눈썹 0f·눈꺼풀 3f·입 6f). - 스미어: full은 손·머리 회전 속도가 임계(예: 손 ≥ 0.5머리/f, 머리 ≥ 20°/f)를 넘는 1프레임만 늘임 그림으로 바꿈. anime는 같은 조건에 오바케 1~2코마. msc2RMfx()가 참이면 둘 다 끔(기존). - 홈 화면 설정 시트의 '움직임 방식' 칸에 세 양식 + 위 표의 '사용자 조정 가능' 항목(koma·stepPerMin·bobHead·swayBodyDeg·holdMaxF·blendF)을 노출하고, 바꾸면 화면 아래 알림으로 즉시 표시(정범님 규칙).

합격 기준 제안 (자동 시험)

  1. 코마 시험: anime 양식에서 몸 트랙 값의 변화 시각 차가 항상 komaBody × 41.7ms의 배수(±2ms)여야 함. 호흡·물리 값은 매 프레임 달라야 함(연속 100프레임 중 같은 값 연속 ≤ 1).
  2. 걷기 케이던스: 10걸음 평균 걸음 시간이 real 541~583ms(13~14f), full 500ms±5%, anime 625ms±5%. 상하 진폭(머리 단위) real 0.13~0.17, anime ≤ 0.1. 접촉 프레임에서 무게중심 높이가 주기 최저, 중간 입각(주기 10~30%)에서 최고.
  3. 홀드 시험: full 양식에서 몸 트랙이 완전히 같은 값으로 12f 넘게 머무는 구간이 0회. anime 양식에서는 36f까지 허용.
  4. 대기 흔들림: real 양식 BodyAngle 진폭 0.2~0.5°, 주 주파수 0.08~0.15Hz(60초 FFT). full 양식 ±2°/15.5s. anime 0.
  5. 깜박임 분포: 5분간 간격 평균 3.5~5.5초, 2초 미만 비율 ≤ 10%; 모양 real/full 6f(±1f), anime 12f(3코마) 또는 8f(2코마).
  6. 표정 순서: 전환 이벤트마다 눈썹 변화 시작 ≤ 눈꺼풀 ≤ 입 ≤ 머리(같거나 뒤) — 100회 중 위반 0.
  7. 블렌드: 끊고 들어올 때 real/full에서 관절 각속도 ≤ blendVelMaxDegF, 블렌드 길이 = blendF±1f. anime는 블렌드 없이 2코마 안에 새 키로 전환.
  8. 짝 동작: 하이파이브 100회에서 두 손 접촉 프레임 차 0f, 손 거리 ≤ 0.05머리; 길이 차 ±25% 초과 시 경고 로그.
  9. 스미어: full에서 스미어 프레임 길이 정확히 1f, anime 1~2코마, prefers-reduced-motion이면 0회.
  10. 양식 전환 무결성: 양식을 바꿔도 뼈대 길이·가동 범위·호흡 주기·깜박임 간격 통계가 변하지 않음(±3%).
