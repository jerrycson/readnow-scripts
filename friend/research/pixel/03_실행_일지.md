# 픽셀 아트 연구 실행 일지

연구 문서, 제작 실험, 제품 반영의 상태를 각각 기록한다. 자료를 읽었다는 사실을 캐릭터 품질이나 엔진 성능의 검증 결과로 바꾸어 쓰지 않는다. 개인 노트와 작업판의 초기 데이터는 이 참고 일지와 별개다.

## 01. 2026-11-15 — 원전 조사와 연구 페이지의 첫 검토본

**목적:** 새로운 픽셀 캐릭터 제작의 판단 근거와 실험 순서를 준비한다.

**수행:** 제작자 원전 13개, Aseprite 공식 문서 7개, MDN 문서 1개를 확인했다. 각 문서에 1줄·1문장·검토 카드 분량의 1페이지 분석·주요 개념·적용 실험·채택 조건을 기록했다. 지속 관찰할 사이트 5곳은 공개 활동 근거와 자료 성격을 함께 기록했다. 전체 시장의 활동 순위를 측정한 것은 아니다.

**구현:** 원전과 사이트 목록을 검색하고, 목차로 이동하고, 검색을 초기화하고, 인쇄할 수 있는 정적 웹페이지를 만들었다. 실행 일지는 수행·미수행·다음 실험을 구분하는 참고 기록이다. 사용자 계정의 노트나 작업을 생성·변경하지 않는다.

**확인:** 원전 페이지에서 21개 카드 표시, 검색어 `onion`의 결과 1개, 없는 검색어의 결과 0개, 초기화 뒤 21개 복귀를 브라우저에서 확인했다. 사이트 페이지 이동과 5개 카드 표시, 원전 목차 이동도 확인했다. 1280px 화면과 390px 화면에서 배치를 점검했고, 작은 화면에서 문서 전체의 가로 넘침이 없었다. 숫자 범위가 아래첨자로 바뀌던 Markdown 표시 오류를 수정했다. 브라우저 오류·경고 기록은 없었다.

**아직 확인하지 않은 것:** 실제 리드나우 운영 웹앱과 PC·안드로이드 앱에서의 표시, 인쇄물의 페이지별 레이아웃, 제작 예제 이미지의 모든 프레임 측정, 유료 원본 파일 분석, 자동 연구 실행, 캐릭터 샘플, 회전 뷰어. 운영 반영은 검토·병합·배포 후 별도로 확인해야 한다.

**첫 연구 가설:** 낮은 해상도의 정보 선택과 방향별 일관성을 함께 검증하면, 세부 장식을 먼저 늘리는 방식보다 수정 원인을 분명하게 찾을 수 있다. 이는 아직 실험하지 않은 가설이다.

**다음 실험:** 같은 새 기본형을 직접 픽셀로 제작하는 방법, 새 3D 기준체를 참고하여 다시 그리는 방법, 절차 렌더링 뒤 교정하는 방법으로 비교한다. 실제 표시 크기의 가독성·회전 일관성·수정 시간·동작 확장 비용으로 판단하고 후보별 실패 사례도 남긴다. 기존 캐릭터의 이미지·메시·리깅·체형 값을 입력으로 사용하지 않는다.

## 02. 2026-11-15 — 보존 실행 검사와 새 기본형·설정 창

**수행:** 옛 운영 본체를 별도로 보존하고 원본 해시를 확인했다. 격리 브라우저에서 24개 캐릭터 그림과 설정 창을 실행했다. 별도 보존 작업의 세부사항은 로컬 기록에서 관리한다.

**선택:** 기존 전체 활용·부분 교체·전면 신규를 비교해, 캐릭터·설정·저장은 새로 만들고 기존 프로그램 연결 규약을 활용하는 부분 교체를 택했다. 세 선택을 모두 완제품으로 구현해 비교한 결과는 아니며, 확인한 원본과 새 연구실의 실행 결과에 따른 현 단계 판단이다.

**구현:** [기본형 연구실](../../pixel-lab/)에 남녀 2~8등신 14기본형, A·B·C 시안, 수평·수직 45도 회전, 64칸 각도표, 기본 설정 창, 로컬 저장·복원·충돌 처리, 비교 메모와 PNG·JSON 내보내기, 바닥·언덕 걷기와 경험 기록을 만들었다. 기존 캐릭터 자산은 사용하지 않았다.

**검사:** 계약 7/7, 실제 브라우저 저장·잠금 6/6 통과. 48px의 세 후보 2,688회전 상태에 빈 그림·잘림·비정상 값이 없었다. 실제 두 탭에서 캐릭터 이동과 동시 설정 충돌 복구를 확인했다. 1280px와 390px 화면을 검사하고, 작은 설정 창의 가로 넘침을 수정했다. PNG가 실제 파일로 저장되었다.

**고친 점:** 이전 설정 복원 때 현재 경험을 유지하도록 했다. 걷기 중 좌우 끝에서 반대쪽으로 순간 이동하던 동작을 방향 전환으로 바꾸었다. 언덕 경계의 높이를 연속 계산하여 표면을 따라 이동하도록 했다.

**현재 한계:** 구조 연구용 마네킹이며 완성 캐릭터가 아니다. 연구실의 생활 무대와 같은 브라우저 창 사이 잠금까지 구현되었다. 실제 기기 간 계정 서버, OS 창 인식, 운영 프로그램 연결과 배포, 옛 연구 렌더의 지정 시점 재현은 완료로 표시하지 않는다. 자동 연구 엔진·노트·작업판은 별도 과제다.

**다음:** 인체 구조 원전과 실제 형태를 비교하여 기본형의 연결·비례를 다듬고, 재질·의상·생물형·애니메이션을 후보별로 누적한다. [복구와 구조 선택의 상세 기록](architecture.html)에 근거와 범위를 기록했다.

## 06. 2026-11-15 · 인체·옷·생물·행동 2차 실험

**목적과 참고:** OpenStax 골격 도해, Met의 인체 조각·울/실크 의복 사진, Muybridge의 보행 사진, Saint11의 금속·걷기·네발 걷기 그림을 직접 비교했다. [상세 관찰과 출처](anatomy.html)에 원전, 적용한 해석, 라이선스와 미검증 범위를 기록했다.

**새 구현:** 연속 몸통 단면과 관절·발 궤적, 체형 3종, 머리 5종, 상의·하의, 면·울·실크·가죽, 장신구 3종을 만들었다. 사람 외에 여우·고양이·새·용·골렘·로봇·외계형을 추가해 총 8종·13시안을 제공한다. 동작 선택·재생·8프레임 PNG 저장과 5종 사물이 있는 재현 가능한 생활 무대를 구현했다.

**발견과 수정:** 기본 자세의 과한 무릎 굽힘, 일부 생물형의 목 연결, 128px 동작 화면의 잘림, 옷 내부 피부의 돌출 가능성을 보정했다. 살펴보기의 주기를 반복 프레임에 맞췄다. 직접 끌거나 움직임 줄이기를 켜면 자율 이동을 중단한다. 저장 중 친구를 바꾸는 경로도 막았다.

**검사:** 렌더 5,312개를 포함한 2차 검사 6/6 통과. 울 코트 잠들기에는 64px 측면의 변화가 읽히지 않는 경고 1건이 남았다. 공간 행동 4/4 통과: 8종 각각 가상 10분에서 사물 5개 방문, 범위 유지, 사건 순서와 기억 일치, 재현번호 결정성을 검사했다. 실제 브라우저에서 사물에 접근한 뒤 반응이 일지에 저장되는 것을 확인했고, 1024×128 PNG 파일을 실제로 내려받았다.

**보존과 한계:** 첫 새 기본형을 별도 체크포인트로 보존했다. 옛 캐릭터 자산은 새 구현에 넣지 않았다. 현재 사물 인식은 이 연구 페이지의 명시적 규칙이다. 실제 OS 인식·다른 기기 간 이동·운영 배포·천과 모발 물리·자동 학습 성능은 미완료다. 앉기 포즈와 의자 접촉, 공을 실제로 이동시키는 반응, 발 미끄러짐은 다음 비교 과제다.

## 07. 2026-11-15 · 보폭과 공 반응 연결

**발견:** 몸 내부의 발 접지만 검사하면 생활 무대의 이동 속도와 보폭이 어긋나는 문제를 놓친다. 그림 하단으로 접지 기준을 매번 바꾸는 것도 뜬 발을 바닥으로 끌어내린다.

**구현:** 화면 이동 거리와 지지 구간을 묶어 보행 위상을 계산한다. 고정된 몸 바닥을 투영해 접지 기준으로 삼는다. 사람형의 공 차기, 지연된 한 번의 공 충격, 튀기·굴림·감쇠·경계 반사, 사물 선택 단추를 추가했다. 화면 크기에 따라 접근 거리가 달라지는 것도 보정했다.

**검사:** 5/5 통과. 평지 반올림 전 지지발 좌표 20,012쌍에서 최대 잔차 약 2.35×10⁻¹⁴px, 공 차기 렌더 1,792개에서 누락·잘림 없음, 공의 지연 충격·착지·완전 정지·반사 확인. 기존 공간 시나리오 4/4도 다시 통과했다. 실제 작은 브라우저 화면에서 공 차기와 방문 기록이 저장되는 것을 확인했다.

**한계와 다음:** 정해진 동작 시점의 충격이며 정밀한 발끝 충돌은 아니다. 픽셀 반올림의 흔들림과 경사면의 양발 접지, 의자 접촉, 사물 간 충돌, 여러 친구의 공동 행동을 계속 비교한다. 새 2차 구현을 체크포인트로 보존한 뒤 진행했다. [상세 기록](anatomy.html#section-8).

## 08. 2026-11-15 · 동물 사진과 변경 전후 비교

**참고와 해석:** Smithsonian 사막여우, CFA 단모 고양이, Cornell Lab 산새의 실제 사진을 직접 비교했다. 특정 동물 사례의 관찰을 모든 종에 일반화하지 않고, 새로운 창작형의 귀·주둥이·가슴·다리·꼬리·날개 연결에 적용했다. 원본 사진은 공개 제품 자산으로 재배포하지 않는다.

**구현:** 여우의 넓은 귀와 좁아지는 주둥이, 고양이의 볼·가슴·후지·올라가는 꼬리, 새의 짧은 목과 접힌 날개·꼬리·발가락을 고쳤다. 새 발가락이 걷기 중 바닥에 남는 문제도 수정했다. [3차·4차 나란히 비교](../../pixel-lab/comparison.html)에서 방향·크기·실루엣을 바꿔 볼 수 있다.

**검사:** 3/3 통과, 추가 렌더 1,856개. 여우·고양이의 정면 실루엣 겹침 비율이 약 0.922에서 0.728로 줄었다. 이는 모양 구분의 지표이며 미적 순위가 아니다. 실제 브라우저에서 세 종류의 변경 전후 표시를 확인하고 화면을 보존했다.

**다음:** 머리와 옷의 작은 크기 가독성, 앉기와 의자 접촉, 반복 동작의 품질을 계속 비교한다. 연구 엔진은 출처·가설·시험·채택 판단을 연결하고 실패 사례가 다음 실험으로 이어지도록 구성한다.

## 09. 2026-11-15 · 연구 엔진의 첫 실제 실행

**구현:** [연구 엔진](../../pixel-engine/)에 원전 21개·사이트 5곳·보충 참고 9개, 총 35개 출처를 연결했다. 등록한 공개 HTTPS 주소의 응답·바이트 해시를 확인하고, 검토된 분석 카드와 실제 검사 보고서에 연결한다. 원문 본문·이미지·계정 정보를 저장하거나 수집 범위를 자동 확장하지 않는다.

**실제 수집:** 35개 중 29개 응답 확인. 접근 거절 3개와 요청 제한 3개는 재확인 항목으로 보존했다. 거절을 우회하지 않으며 실패가 기존에 읽은 분석을 삭제하지 않는다. 페이지 바이트 변경은 검토 신호이지 새로운 주장의 검증 결과가 아니다.

**실패의 누적:** 검사 합계와 개별 결과를 확인한 뒤 실패·작은 동작 경고·출처 상태를 다음 실험으로 분류한다. 같은 근거는 중복 계수하지 않으며, 검사하지 않은 영역의 경고는 열린 상태를 유지한다. 후보 채택 계약은 조정 사례와 평가 사례의 중복, 필수 결과 누락, 퇴보, 시각 검토 누락을 구분한다.

**검사:** 엔진 자체 7/7 통과. 원전 중복·잘못된 검사 합계·실패 우선순위·중복 근거·평가 누수·이동 호스트 제한·본문 크기·HTTP 거절을 검사했다. 실제 보고서 7묶음, 38/38 결과를 집계했다. 동일 입력으로 두 번 실행해 이력 1개와 근거별 관측 수 1을 유지했다. 열린 항목은 동작 경고 1건과 출처 재확인 6건이다.

**현재 범위:** 자동 요약 작성, 신경망 학습, 코드의 자가 수정, 무인 배포는 구현하지 않았다. 실행 화면은 마지막 결과를 읽으며 백그라운드 반복 수집 스케줄은 설치하지 않았다. 이 단계의 엔진 화면은 HTTP 전달·파일 연결을 검사했고 실제 브라우저 조작 검증은 아직 하지 않았다. 다음은 경고가 실제 수정·재검사·채택 판단으로 닫히는 한 주기를 실행하는 것이다.

## 10. 2026-11-16 — 첫 경고의 수정·평가·재검증

수면 시 울 코트가 정지해 보이는 입력을 재현하고 국소 호흡 다섯 강도를 비교했다. 0.08을 채택해 옷과 몸통이 함께 움직이게 했고 목·골반과 바닥 접촉을 유지했다. 문제 입력의 구분되는 프레임은 1 → 4, 조정하지 않은 각도·크기 여섯 사례의 합은 26 → 47이었다.

## 연구 엔진의 검증 계약

수집 → 출처 확인 → 주장과 근거 분리 → 실험 제안 → 시험 제작 → 보류한 평가 자료로 비교 → 채택 또는 기각 → 적용 후 재검증을 하나의 기록으로 연결한다. 현재 등록 출처 수집·검사 집계·실패 기억·후보 계약을 실행형 엔진으로 구현했다. 이 문서 자체가 백그라운드에서 수집하거나 학습하는 것은 아니다.

성능은 방향 오류, 발 미끄러짐, 누락 프레임, 수정 시간, 처리 비용처럼 측정할 항목과 사람이 판단할 미적 취향으로 나눈다. 훈련에 쓴 사례로만 성능을 평가하지 않고, 실패했을 때 마지막 정상판으로 돌아갈 수 있어야 한다. 연구 엔진이 배운 제작 규칙과 개별 캐릭터가 경험으로 형성한 기억·성격은 다른 데이터로 관리한다.

향후 일지 항목에는 날짜, 목적, 출처, 가설, 후보, 고정 조건, 변경 변수, 결과 파일, 평가 방법, 실패, 채택 이유, 다음 실험을 남긴다. 실행하지 않은 검사는 ‘미수행’으로 표시한다.
