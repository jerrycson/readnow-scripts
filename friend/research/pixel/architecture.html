이 공개 페이지는 공개 운영판의 실행 검사와 새 연구실 구현을 기록한다. 별도 보관 자료의 세부 목록과 검증 보고서는 로컬 보존 기록에서 관리한다. 새 캐릭터에는 기존 캐릭터 자산을 사용하지 않는다.

03. 세 가지 시스템 선택의 비교

선택 확인한 장점 확인한 복잡성 이번 선택
기존 시스템 전체 활용 기존 그림·설정 창이 다시 실행됨. 운영 연결이 이미 있음 큰 본체 안에 SVG 그림·설정·계정 저장이 결합됨. 기존 기기 선택 규칙이 새 캐릭터별 단일 존재 규칙과 다름 채택하지 않음
부분 교체 새 캐릭터·설정·저장을 독립 검증하면서 기존 PC·안드로이드 연결 규약을 활용 가능 계정 서버와 실제 프로그램 연결을 별도로 구현·검사해야 함 현 단계 채택
프로그램까지 전면 신규 경계를 새로 설계할 수 있음 투명 창, 클릭 통과, 배율, 단축키, 안드로이드 서비스와 권한까지 재구현·재시험해야 함 필요가 입증될 때 재검토

세 선택을 모두 완제품으로 만들어 속도를 측정한 비교는 아니다. 기존 원본 실행, 저장 의존성 확인, PC·안드로이드 코드와 연결 규약 조사, 새 연구실의 실제 구현 결과를 근거로 결정했다. 현재 가장 작은 변경 범위에서 독립 검증 가능한 선택이다.

새 연구실의 모델·렌더러·저장·설정 창은 새로 작성했다. 기존 프로그램에서는 연결 메시지의 형식만 참고한 얇은 어댑터를 둔다. 실제 프로그램 화면이 이 연구실로 교체된 상태는 아니다. 운영 경로 전환은 별도 출고 검증을 거친다.

04. 새 기본형과 설정 창의 첫 구현

  • 남성·여성 각각 2~8등신, 총 14개 중립 연구 마네킹. 옷·머리·장비가 없는 형태로 시작한다.
  • 구조 후보 A·B·C는 몸 연결과 굵기가 다른 세 가지 시안이다. B를 임시 기본으로 두었으며 미적 최종안으로 확정하지 않았다.
  • 수평·수직 각각 0~315도, 45도 간격. 수평 회전 후 수직 회전을 적용하며 각 상태의 깊이와 가림을 다시 계산한다.
  • 기본형 목록, 64칸 각도표, 드래그·키보드 회전, 현재 PNG 저장, 후보 선택과 비교 메모를 제공한다.
  • 설정 창에서 이름·기본형·등신·구조·해상도·표시 배율·팔레트·걷기 속도·움직임·격자를 바꾼다. 미리보기, 취소, 저장, 이전 설정 복원을 제공한다.
  • 기록은 별도 IndexedDB에 저장하며, 동시 저장 충돌을 감지한다. 충돌 시 입력을 보관한 뒤 최신값을 읽고, 앞선 입력을 명시적으로 다시 적용할 수 있다.
  • 이전 설정을 복원해도 현재 경험 기록은 유지한다. 전체 연구 기록을 JSON으로 내보낼 수 있다.
  • 생활 무대는 이 페이지 안의 바닥과 언덕을 걷고, 가로로 옮겨도 표면 높이를 따른다. 돌봄·탐색·연습은 경험으로 누적하고 성격을 미리 고정하지 않는다.

같은 브라우저의 연구 창 사이에서는 캐릭터별 잠금을 사용한다. 새 창이 표시되기 전에 이전 창을 숨긴다. 서로 다른 캐릭터를 다른 창에 나누어 둘 수 있다. 실제 계정·다른 기기 간 이동은 서버가 필요하며 아직 연결하지 않았다.
