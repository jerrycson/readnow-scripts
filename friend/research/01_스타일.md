# 01. 스타일 — TV 애니메이션 설정표 화풍 · 선 · 셀 그림자 · 색 · LOD

정범님 정의(10/27 16:24): "아니메풍 = TV 애니 설정표(キャラクター設定・設定資料) 화풍". 근거: `web/anime_style.md`(출처 30 · [N번호]) · 참고 그림([그림ID]) · v1 §0.3.

## 1.1 설정표(모델 시트)란 무엇을 담는가 (A11.2·A11.4의 기준)
- 표준 구성: **정면·측면·배면 3면** + 기본 동작 + 희로애락 표정집 + 복장 변형 + 소품 + 신장 비교표. 색은 뒤 공정 '색채설계'가 따로 정한다 [N3]. 머리·몸 회전 그림, 손·발 스케치, "머리 모양·길이·눈·입의 크기와 위치" 메모가 들어간다 [N4].
- 색 지정표 단계 이름: **ハイライト / ノーマル / 1号影 / 2号影** 4단 [N5·N6]. TV 시리즈 한 작품 ノーマル색 약 120색 [N7~N9].
- **우리 설정 시트**(11 §11.6)는 이 구성을 그대로 따른다: 3면도 + 고유 요소(고정/가변 표시) + 표정 40+ 얼굴 썸네일 + 몸짓 96 + 소품 + 색 4단 표 + 신장 비교(1H = 여 22.5cm·남 23.5cm).
- 공정 용어(용어집): キャラクターデザイン·色彩設計·色指定·原画·動画·中割り·溜め(타메)·詰め(츠메)·動検·実線·色トレス線·影指定·撮影.

## 1.6 도형 언어·정체성 (A11.2)
- 1차 도형 둥근 달걀(친근) · 2차 작은 원(하이라이트·홍조·단추) · 캐릭터마다 강조 1개(눈 또는 고유 소품) [8fa7d8f4·d10d11e3].
- **고유 요소 2~3개**(머리 실루엣 요소·장신구 1·눈색)는 옷·표정·SD에서도 불변. 설정 시트에 '고정/가변'을 표시 [570eb4e6·7034e091].
- 둥근 꼴 = 친근, 네모 = 안정, 세모 = 위험 · SF = 깨끗한 기하, 판타지 = 흐르는 곡선 + 절제된 뾰족함 [web/props_clothes 44·45].
