연구 등록
이 화면은 두 연구의 고정 ID와 목적·점수를 표시합니다. 중앙 등록 상태는 별도 확인 대상입니다.
엔진 코드
실험 도구가 실제 형상을 계산하고 어댑터가 측정과 검토 선택을 공통 형식으로 읽습니다.
예약 회차
중앙 공개 요약을 오늘과 어제의 한국 날짜로 조회합니다. 브라우저에서 수행한 회차 시각은 이 기기 일지에 쌓입니다.
일지
각 회차의 관찰·행동·근거·결과를 추가합니다. 측정일이 없는 공개 묶음은 최초 게시 시각으로 구분합니다.
채점과 단계
동일 조건의 독립 사람 점수, 최소 표본과 연속 개선 기준이 있어야 단계 상승을 판단합니다.
고쳐 나가기
재료가 36시간 넘게 멈추면 원본을 다시 읽습니다. 재조회 뒤에도 정체되면 경고를 남깁니다.
실제 연결
정밀 조형과 내 참고그림에서 후보를 직접 확인하고 기존 화면에서 선택합니다.

아래 결정은 근거를 장부에 추가한 행동입니다. 자동 적용 확신은 0으로 보류하며 원래 모형이 추정한 확률은 수집되지 않았습니다. 무작위 실험 배정과 사람 점수가 없으면 빈 칸으로 남깁니다.
