# 책방 친구 연구 엔진 1차

현재 구현은 등록한 공개 원전의 응답·변경 여부, 검토된 분석 카드, 실제 검사 보고서, 다음 실험 항목을 연결하는 작은 실행 단위다. 모델 학습·자동 코드 수정·무인 배포는 하지 않는다. 자료를 많이 읽었다는 사실을 캐릭터 품질의 향상으로 집계하지 않는다.

## 실행

Node.js의 표준 라이브러리만 사용한다. 이 폴더에서 다음 순서로 실행한다.

```sh
node test.mjs
node collect.mjs --run
node run.mjs
```

정적 HTTP 서버에서 `index.html`을 열면 마지막 결과와 자료 색인을 확인할 수 있다. 화면을 열었다고 수집 작업이 실행되지는 않는다. 별도 반복 스케줄은 아직 설치하지 않았다.

## 수집 범위

`sources.json`의 원전 21개·사이트 5곳·보충 참고 9개, 총 35개만 확인한다. HTTPS와 등록한 호스트로 범위를 제한하고, 한 번에 두 요청, 응답 시간 8초, 본문 최대 1MB를 적용한다. 인증 정보·계정 자료·유료 자료를 수집하지 않는다. 원문이나 이미지를 보관·재배포하지 않고 바이트 수·SHA-256·응답 상태만 기록한다. 거절·시간 초과·다른 호스트로의 이동은 보류로 남긴다.

`baselineHash`는 처음 확인한 바이트의 기준점이다. 해시 변화가 의미 있는 내용 변화라는 뜻은 아니다. 변경된 페이지를 읽고 연구 카드의 차이를 기록한 뒤에만 기준 해시를 갱신한다. 새 해시가 반복해서 관측됐다는 이유로 경고가 저절로 해제되지는 않는다.

요약과 해석은 기존에 검토한 연구 카드에 연결한다. 수집기는 새 원문의 1줄·1문장·1페이지 분석을 스스로 작성하지 않는다. 후속 자동 분석을 연결할 때도 출처별 근거와 실제 검증을 분리해야 한다.

## 검사에서 다음 실험으로

`run.mjs`는 기본형 연구실의 결과 JSON 합계와 개별 항목을 검증한다. 실패는 높은 우선순위로, 작은 동작의 식별 경고는 다음 시각 비교로, 수집 실패는 출처 재확인으로 분류한다. 같은 근거의 중복 읽기는 관측 수를 늘리지 않는다. 검사하지 않은 영역의 예전 경고는 열린 상태를 유지한다. 동일한 전체 근거에서는 새 실행 이력도 만들지 않는다.

`evaluateCandidate`는 조정 사례와 평가 사례가 겹치거나, 필수 검사값이 없거나, 시각 판단이 남으면 보류한다. 누락·잘림·비정상 출력 또는 목표 지표의 퇴보가 있으면 기각한다. 수치와 시각 검토가 모두 통과하면 적용 가능한 후보로 표시할 뿐, 운영판을 바꾸지는 않는다. 기존 개발 사례가 과학적으로 독립적인 평가 데이터라고 주장하지 않는다. 앞으로 실험을 시작하기 전에 사례 분리를 고정하는 계약이다.

## 데이터와 복구

- `sources.json`: 검토된 출처 색인과 분석 페이지.
- `collection.json`: 가장 최근 수집 상태와 기준 해시.
- `status.json`: 실제 보고서의 집계, 해결·미해결 기록, 서로 다른 근거의 실행 이력.
- `tests.json`: 이 엔진 자체의 검사 결과.

체크포인트는 로컬에 별도로 보존한다. 현재 목표는 실패를 잊지 않고 다음 비교를 더 정확히 정하는 것이다. 인간보다 뛰어난 미적 판단이나 스스로 지속 학습하는 성능은 구현·검증되지 않았다.
