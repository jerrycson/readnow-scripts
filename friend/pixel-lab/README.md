# 책방 친구 픽셀 기본형 연구실

기존 캐릭터 자산을 사용하지 않고 새로 만든 독립 연구 페이지다. `/friend/pixel-lab/`를 정적 HTTP 서버로 열면 된다. 외부 패키지 설치나 빌드 과정은 없다. 기록은 이 출처의 IndexedDB에 저장된다. 서버 주소나 포트가 바뀌면 다른 저장 공간이므로 먼저 JSON으로 내보낸다.

남녀 각각 2~8등신, A·B·C 구조 시안, 수평·수직 각각 45도 간격 회전, 설정 미리보기·저장·이전 설정 복원, 충돌 입력 복구, PNG·연구 기록 내보내기, 같은 브라우저의 캐릭터별 활성 창 관리, 바닥과 언덕 걷기를 포함한다. 구조 연구용 마네킹이며 완성 캐릭터가 아니다.

## 2차 형태·재질·동작 연구

인체 표면을 흉곽·허리·골반의 연속 단면으로 만들고, 지지발과 옮기는 발을 구분했다. 사람·여우·고양이·새·용·골렘·로봇·외계형 8종, 의상 조합 13시안, 체형·머리·상하의·재질·소품 설정을 제공한다. 동작 연구에서 지원 동작의 핵심 8프레임을 선택·재생하고 PNG로 저장한다.

생활 무대에는 책꽂이·화분·공·의자·등이 있다. 재현번호에 따른 배치, 선택·접근·관찰·반응, 사물 방문 기억과 로컬 일지를 구현했다. 실제 OS나 일반 웹사이트를 인식하는 기능은 아니다. 3차에서 화면 이동과 보폭을 연결하고 사람형 공 차기·공의 이동과 튀기를 추가했다. 경사면 접지·의자 접촉·발끝의 정밀 충돌은 후속 검증 대상이다.

실제 참고 사진·자료의 해석과 적용은 `../research/pixel/anatomy.html`에 있다. 박물관의 Public Domain 사진은 연구 페이지에 출처를 붙여 표시하며, OpenStax와 Saint11 원본 그림은 제품 자산으로 포함하지 않는다.

## 3차 보행·공 반응

`node qa/test-motion.mjs`: 지지발 좌표 20,012쌍, 공 차기 렌더 1,792개, 고정 바닥 기준, 지연 충격·착지·정지·반사의 5/5 검사 통과. 평지의 반올림 전 좌표에서만 발 미끄러짐 잔차를 측정했다. 실제 작은 화면에서 공 반응과 기록을 확인하고 좁아지던 생활 무대 제목 배치를 고쳤다.

## 4차 동물형 비교

`comparison.html`에서 새 프로젝트의 3차·4차를 나란히 비교한다. 실제 동물 사진의 큰 형태를 참고해 여우·고양이·새를 구분하고 발가락 움직임을 고쳤다. `node qa/test-animals.mjs` 3/3 통과, 1,856개 렌더 검사. 출처와 한계는 인체·재질 연구 페이지 4차 기록에 있다.

## 파일 경계

- `model.mjs`: 설정·프로필·경험·접지 계약.
- `geometry.mjs`, `anatomy.mjs`, `creatures.mjs`: 새 메시·인체 관절·동물과 창작 생물형.
- `materials.mjs`, `renderer.mjs`: 재질별 팔레트·명암, 수평 다음 수직 회전, 깊이 판정, 소프트웨어 픽셀 렌더링.
- `motion.mjs`: 표시 이동 거리와 보행 위상의 연결.
- `catalog.mjs`, `world.mjs`: 형태 시안·지원 동작, 재현 가능한 사물 배치와 행동.
- `storage.mjs`: 별도 IndexedDB, 수정 번호 검사, 이력과 일지의 원자적 저장.
- `presence.mjs`: 같은 출처·브라우저의 Web Locks/BroadcastChannel 점유. 계정 서버용 순수 상태 전이 계약도 포함하나 서버 구현은 아니다.
- `host-bridge.mjs`: 기존 PC·안드로이드 메시지 형식의 어댑터. 실제 프로그램 연결은 미완료다.
- `app.mjs`, `index.html`, `style.css`: 연구 화면과 설정 창.

## 확인

Node.js에서:

```sh
node --input-type=module -e "import('./friend/pixel-lab/tests.mjs').then(async m=>{const r=await m.runPureTests(); console.log(JSON.stringify(r,null,2)); if(r.passed!==r.total)process.exitCode=1;})"
```

`browser-tests.html`의 검사 실행 단추는 별도의 임의 이름 데이터베이스에서 저장 충돌·복원·캐릭터별 잠금을 검사한다. 운영 계정과 기존 캐릭터 저장소를 읽거나 쓰지 않는다. 시험 데이터베이스에는 시험 데이터만 들어간다.

2026-11-15: 순수 계약 7/7, 실제 브라우저 검사 6/6 통과. 48px에서 A·B·C × 14기본형 × 64상태 = 2,688개를 검사했다. 실제 두 탭 전환, 설정 저장·새로고침·복원·충돌 입력 복구, 1280px·390px 배치, PNG 내려받기를 확인했다. 상세 결과와 한계는 `../research/pixel/architecture.html`에 있다.

2차: `node qa/test-v2.mjs`, `node qa/test-world.mjs`. 렌더 5,312개를 포함한 6/6, 공간 행동 4/4, 실제 브라우저 저장 6/6 통과. 64px 측면에서 울 코트의 잠들기 프레임 변화가 읽히지 않는 경고 1건이 남았다. 실제 1024×128 PNG 내보내기와 390px 확장 설정 배치를 확인했다. 결과 JSON은 `qa/`에 있다. 테스트 실행은 결과 JSON만 갱신한다.

계정 기반 다른 기기 간 이동, 실제 OS·앱 지형 인식, 운영 PC·안드로이드 연결, 연구 자동 실행과 완성 미술 품질은 아직 검증되지 않았다. 기존 서비스나 캐릭터 모드를 자동으로 바꾸지 않는다.
