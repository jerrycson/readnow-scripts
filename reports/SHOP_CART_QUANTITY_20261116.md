# 우리숍 첫 담기와 삭제 되돌리기의 수량 보존 — 2026-11-16

## 문제와 수정

기준은 PR #15의 ccf953d1e2587e55d982598a20ae27bdd2d1b1eb다. 실제 고객 화면을 합성 자료로 열어 390px·1280px에서 두 결함을 확인했다. 재고 3권 상품을 처음 담으면 장바구니에 재고 q가 빠져 수량 단추가 나오지 않았다. 2권을 삭제하고 되돌리면 선택 수량 n이 빠져 1권이 됐다. 첫 검사는 의도한 단언 4개가 모두 실패했고 브라우저 자체 오류는 없었다.

cartAdd는 첫 줄에도 유효한 여러 개 재고 정보를 보존한다. 선택 수량은 여전히 1이며 한 권 주문 글에 qty를 추가하지 않는다. cartRestore는 삭제 당시 선택 수량·가격·단위·부가 칸을 보존한다. 다른 탭이 같은 상품을 다시 담았거나 종류 수 제한에 걸리면 새 자료를 덮지 않는다. 현재 여러 권 설정·기억된 재고 한도 안에서 원래 수량을 복원할 수 없으면 수량을 줄여 저장하지 않고 안내한다.

되돌린 줄에는 새 식별자를 발급한다. 이전 주문이 늦게 완료돼도 삭제 후 되돌린 책을 이전 줄로 보고 제거하지 않는다. 저장은 #15의 동일 잠금 경로를 이용한다. 새 함수가 없는 옛 계산 모듈과 섞이면 새로고침을 안내한다. 실제 재고 확정은 기존 서버 검사가 계속 담당한다.
